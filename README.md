# Лабораторная работа №1

## Сбор информации об операционной системе

Программа определяет операционную систему, в которой она была
запущена, собирает основные сведения о системе и сохраняет
результат в файл формата JSON.

Скрипт предназначен для работы в:

- Windows
- Linux
- macOS

## Запуск

Для запуска программы необходимо выполнить:

bash
python OS.py
